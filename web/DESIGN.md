# REA 网页工作台设计

产品：中文软件拆解助手，本机浏览器使用。主任务是提问、查看执行过程、追溯原始证据。

Refero 在线服务在本次设计中返回 NO_SUBSCRIPTION；使用其随技能提供的 color.md 和 craft-details.md 作为规范依据，未声称研究过在线产品截图。

锁定方向：白色内容画布、灰色会话侧栏、深灰主要动作、蓝色仅用于焦点和选中态。系统无衬线字体，正文 14px，12px 次要信息。用户提出的 Personal Agent 类体验决定会话列表与聊天输入；拆解任务决定可展开的证据面板。使用原生控件和代码实现，无摄影或装饰图像。

| 决策                                  | 来源                            | 用途                     |
| ------------------------------------- | ------------------------------- | ------------------------ |
| 中性色、少量强调色                    | Refero color.md 的产品界面规则  | 长时间阅读与证据密度     |
| 有标签的输入、focus-visible、错误状态 | Refero craft-details.md         | 键盘操作、配置纠错       |
| 会话列表与持续追问                    | 用户的 Personal Agent 参考      | 保持熟悉的使用方式       |
| 独立证据面板                          | 原引擎 Evidence provenance 契约 | 保留事实与推断的追溯来源 |
| 本机工作空间提示                      | 原项目 local-only 架构          | 明确分析目标所在机器     |

验证：桌面实际浏览器截图检查；手机宽度检查布局和模型设置入口。证据面板叠加显示于窄屏。
